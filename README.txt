NAVRUP INDIA HR MANAGEMENT — VERSION 3
Free static website. No server/database required.
Features: Admin login screen, employee records, attendance, Salary Slip, Service/Experience Certificate, Relieving Letter, print/save as PDF.
Data is stored in the browser's localStorage on the device/browser where it is used.

IMPORTANT:
- This is a free prototype suitable for internal/local use.
- The login in this version is a front-end demo, not secure authentication.
- For a real multi-user online HR system, connect a backend/database and real authentication.
- To publish free: upload index.html, style.css and app.js to any static hosting service.
